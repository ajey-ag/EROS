   `claude binary not found` — the VS Code Claude Code extension had
   auto-updated (`2.1.202` → `2.1.207`), so the path pinned in
   `.eros/config.local.toml` no longer existed. Rewrote
   `ClaudeCodeProvider._binary()` to auto-discover the newest installed
   `anthropic.claude-code-*` extension directory when `binary` is left at its
   default `"claude"`, and cleared the pinned path from `config.local.toml`.
   This should survive future extension updates without manual fixes.
