## Rate Limiter Zoo — summary

Five classic rate-limiting algorithms (token bucket, leaky bucket, fixed
window, sliding log, sliding window counter) behind one interface, with
hypothesis-based property tests proving each algorithm's actual bound and a
deterministic benchmark harness comparing throughput and burst behavior.

**What makes it a portfolio piece, not just an exercise:** the write-up's
every number is regenerated by two commands (`pytest`, `python -m
ratezoo.bench`) rather than hand-collected, so a reader can independently
verify every claim — including the ones that are unflattering to the fastest
algorithm (fixed window admits 2x capacity at a window boundary — a machine-
checked property test, not a caveat in prose).

Built end-to-end through EROS: idea (score 16/25) -> charter -> architecture
-> 8 dependency-ordered tasks -> Claude Code headless dispatch -> LLM review
-> shipped, at a total agent cost of $1.80 across 8 runs. Full lifecycle is
inspectable via `eros status rate-limiter-zoo` or the dashboard.
