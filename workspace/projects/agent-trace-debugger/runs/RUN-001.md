What I created:

- **`pyproject.toml`** — setuptools build, Python 3.11+, zero runtime dependencies, `pytest` under a `dev` extra and `anthropic` under a `demo` extra.
- **`tracedbg/trace.py`** — the core schema and store:
  - `SCHEMA_VERSION = 1` plus a `KNOWN_SCHEMA_VERSIONS` set for the loader.
  - Dataclasses `ToolCall`, `Step`, `TraceHeader`, and `Trace`, each with explicit `to_json`/`from_json` so serialization order is deterministic (which matters later for the rerunner's byte-identical prefix guarantee).
  - `TraceWriter` — writes the header line on open, `append(step)` writes one JSONL line and flushes immediately (crash-safe partial traces), usable as a context manager, opened with `newline="\n"` so line endings are consistent on Windows.
  - `load_trace(path)` — validates `type == "header"` and a known `schema_version` on line 1, tolerates unknown fields on all records, skips unknown record types for forward compatibility, and raises `ValueError` with file/line context on malformed JSON, missing header, or unknown version.

- **`docs/trace-format.md`** — documents the JSONL layout, all header/step/tool-call fields for version 1, and the append-only / unknown-fields-tolerated / version-bump rules.
- **`tests/test_trace.py`** — 7 tests: 3-step round-trip equality, unknown extra fields on header and step lines tolerated, missing header raises, empty file raises, malformed JSON line raises, unknown schema version raises, and a partial trace (header + 1 step, writer never closed) loads as a valid 1-step trace.
