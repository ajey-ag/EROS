# RUN-002 — TASK-002: Recorder instrumentation API

## Agent summary

All 14 tests pass (7 new recorder tests plus the existing trace tests).

**What I created:**

- `tracedbg/recorder.py` — the `Recorder(path, agent="", task="")` context manager wrapping `TraceWriter`. It writes a header with a real `created_at` timestamp on open, then:
  - `begin_step(prompt, model)` opens a step with the next index and an ISO 8601 `started_at`; raises `RuntimeError` if a step is already open.
  - `log_tool_call(name, args, result)` appends a `ToolCall` to the open step; raises `RuntimeError` if none is open.
  - `end_step(output)` stamps `ended_at`, appends the step via `TraceWriter` (which flushes immediately), and closes the step.
  - Context exit (or `close()`) discards any unfinished step and closes the file, so the trace on disk only ever contains completed steps.

- `tests/test_recorder.py` — covers the acceptance criteria: two recorded steps load back with indices 0 and 1 plus correct tool calls and outputs; a begun-but-unended step is absent after close while completed steps remain parseable (simulated crash); `log_tool_call`/`end_step` outside a step and double `begin_step` all raise `RuntimeError`; steps are readable on disk before the recorder closes (flush guarantee); and an empty run still leaves a valid trace with just a header.
